# portfolio_Website

A modern and fully responsive personal portfolio website built using HTML5 and CSS3.
This project showcases a professional frontend developer portfolio with smooth animations, responsive layouts, glowing effects, and modern UI sections.

**🚀 Features**
Responsive Navigation Bar
Animated Background Effects
Hero Section with Profile Image
About Me Cards
Skills Progress Bars
Project Showcase Section
Contact Form UI
Smooth Hover Animations
Modern Gradient Design
Fully Responsive Layout

**🛠️ Technologies Used**
HTML5
CSS3
Google Fonts (Poppins)
